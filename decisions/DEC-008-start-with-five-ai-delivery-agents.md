# DEC-008: Start With Five AI Delivery Agents

Status: Accepted

## Decision

Start the AI/software organization with five roles:

- Product Manager / Orchestrator.
- UX / Product Designer.
- Full-Stack Engineer.
- QA Engineer.
- DevOps / Platform Engineer.

## Reason

This covers planning, design, implementation, quality, deployment, and operations without over-fragmenting the team.

## Implication

Add restaurant domain, analytics, separate frontend, and separate backend roles later.
