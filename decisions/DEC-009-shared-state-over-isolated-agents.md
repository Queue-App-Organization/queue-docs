# DEC-009: Shared State Over Isolated Agents

Status: Accepted

## Decision

Agents should coordinate through Jira, GitHub, docs, CI/CD, and analytics.

## Reason

Shared state creates a durable operating system for the project and avoids reliance on conversational memory.

## Implication

Product decisions belong in docs; implementation work belongs in tickets and PRs.
